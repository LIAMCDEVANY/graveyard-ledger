# 🪦 Graveyard Ledger

Graveyard Ledger is a dark-themed Django CRUD journaling application where users can create, manage, and revisit personal entries.

Each entry acts as a preserved thought, memory, regret, or reflection within a personal archive. The project was built using Django, PostgreSQL-ready architecture, and Django’s built-in authentication system.

## ✨ Features

- User authentication (sign up, login, logout)
- Full CRUD functionality
- User-specific entries
- Authorization and protected routes
- Dark themed responsive UI
- Raven branding and custom styling
- Django template inheritance
- PostgreSQL-ready configuration

- Python
- Django
- PostgreSQL
- HTML
- CSS

---

## 🔒 Authorization Features

- Users must be logged in to create, edit, or delete entries.
- Users may only modify or view their own entries.
- Protected routes use Django authentication decorators.
